# PIRLS 2021 bullying and reading achievement

Analysis of the association between student bullying and reading achievement in
South Africa and Brazil using the PIRLS 2021 international database.

## Project structure

- `data/raw/`: unmodified PIRLS 2021 SPSS files for Brazil (`BRA`) and
  South Africa (`ZAF`), plus local cache files generated by `EdSurvey`.
- `scripts/00_packages.R`: checks the small set of R packages used by the
  project and can install any that are missing.
- `scripts/01_data_audit.R`: checks the two main student files, their identifiers,
  survey-design fields, bullying measures, and reading plausible values.
- `output/`: generated tables and figures (do not edit these by hand).

The main analysis file has not yet been added to the repository. Add it under
`scripts/` before substantive code cleaning or model estimation.

## R setup

The project uses R 4.4 or later and this deliberately small package set:

| Package | Use |
|---|---|
| `here` | project-relative file paths |
| `EdSurvey` | PIRLS import, merges, plausible values, weights, and JRR analysis |
| `dplyr` | data preparation |
| `broom` | tidy model output |
| `ggplot2` | figures |

Check the packages from the project root:

```r
source("scripts/00_packages.R")
```

To install missing packages on a new computer:

```powershell
Rscript scripts/00_packages.R --install
```

Then audit the input files:

```powershell
Rscript scripts/01_data_audit.R
```

## Data notes

The analysis uses the official `.sav` files through:

```r
library(EdSurvey)
pirls <- readPIRLS(path = "data/raw", countries = c("zaf", "bra"))
```

The legacy `.Rdata` files are not used by the project. `readPIRLS()` processes
the student, school, teacher, and linkage files and caches its converted files
in `data/raw/`. The first run can take several minutes; later reads use the
cache.

`getData()` extracts the fields needed for the core analysis:

- identifiers: `IDSTUD`, `IDSCHOOL`, `IDCLASS`;
- gender: `ASBG01`;
- home-resources scale and index: `ASBGHRL` and `ASDGHRL`;
- reading plausible values: `ASRREA01` through `ASRREA05`;
- bullying scale and index: `ASBGSB` and `ASDGSB`;

Keep the `edsurvey.data.frame` objects for inferential analysis with EdSurvey
functions. The ordinary data frames returned by `getData()` are intended for
auditing, recoding, and descriptive inspection, not as a replacement survey
design for final models.

The current files contain 4,941 students in 187 schools for Brazil and 12,422
students in 321 schools for South Africa. These counts differ from the classroom
Stata example (12,810 students and 293 schools), so that do-file should be used
as a conceptual reference rather than as code or a count benchmark.

## Methodological guardrails

- Keep identifiers as identifiers; do not interpret their means.
- Let `EdSurvey` manage PIRLS omitted levels and study-specific missing values.
  The audit preserves omitted categories so that it can verify the full sample;
  exclude them explicitly as appropriate for each model.
- Use `TOTWGT` for national population-representative estimates. In a pooled
  cross-country analysis, this gives more influence to countries with larger
  student populations. Use `SENWGT` instead when the estimand requires each
  country to contribute the same total weight (500 per country).
- Use EdSurvey analysis functions so the PIRLS jackknife repeated replication
  weights are applied automatically. Ordinary standard errors or simple school
  clustering are not substitutes.
- Use all five reading plausible values and combine both sampling and imputation
  uncertainty. Do not use only `ASRREA01` for final inference.
- Treat `ASBGSB` as a Rasch-scaled context score and `ASDGSB` as its categorical
  index; they are not simple sums of `ASBG11A` through `ASBG11J`. A higher
  `ASBGSB` score indicates less frequent bullying. Scores at or below 7.7 are
  categorized as "About Weekly," scores above 7.7 and below 9.2 as "About
  Monthly," and scores at or above 9.2 as "Never or Almost Never."
- Analyse countries separately or ensure that jackknife zones are uniquely
  identified by country before fitting a pooled country-interaction model.
- Report context-variable missingness. PIRLS flags results above 15% missing and
  does not report country results with less than 40% of students represented or
  achievement results for categories containing fewer than 2.5% of students.

Before finalising the estimation code, check it against the
[PIRLS 2021 International Database and User Guide](https://www.iea.nl/publications/user-guides/pirls-2021-international-database-and-user-guide).
The relevant Brazil and South Africa SPSS files are already present.
